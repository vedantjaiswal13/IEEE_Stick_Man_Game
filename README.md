# ⚡ IEEE SB VIT Pune: Cyber Clash (Stickman Showdown)
### Official Interactive Tech Fest & Publicity Booth Showcase
**Reference:** [ieeesbvitpune.vercel.app](https://ieeesbvitpune.vercel.app/) • Vishwakarma Institute of Technology, Pune

An action-packed, futuristic 2-player stickman combat simulation designed for the **IEEE Student Branch at Vishwakarma Institute of Technology (VIT), Pune**. Built for tech fest exhibitions, orientation week booths, and student recruitment.

---

## ⏱️ Dynamic Match Duration Pacing (Accurate Fight Timing)

- **Configured Fight Duration (20s, 30s, 45s, 60s, 90s)**:
  - Fights **strictly adhere to the chosen time set earlier**!
  - Combat damage and hit scaling dynamically calibrate according to the selected duration.
  - **Survival Adrenaline Buffer**: Prevents premature knockouts while there is still time on the clock, keeping both fighters in a tense, back-and-forth duel.
  - **Climax Intensity**: In the final 10 seconds, intensity surges, damage multipliers unlock, and the decisive Knockout blow strikes at the buzzer!
